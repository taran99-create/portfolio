# ReactNova — Modern React.js Application

A modern, high-performance React application built with **React 18**, **Vite**, and **Vanilla CSS Design System**.

## 🚀 Features

- ⚡ **Lightning Fast**: Powered by Vite for instant Hot Module Replacement (HMR).
- 🎨 **Glassmorphic UI**: Beautiful dark mode palette, smooth gradient accents, and responsive layout.
- 🧩 **Modular Components**: Cleanly separated components (`Navbar`, `Hero`, `Features`, `Projects`, `Skills`, `Contact`, `Footer`).
- 📱 **100% Responsive**: Tailored for mobile, tablet, and widescreen desktop views.
- ✨ **Interactive State**: Built-in dynamic state counters, filterable project tabs, and live message handling.

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or newer) installed.

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

The application will start locally (usually on `http://localhost:3000` or `http://localhost:5173`).

### 3. Build for Production

```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
